# 数据文件说明（本目录内容不入库）

流水线解析的是**仪器导出的文本格式**（常见于源表自带软件导出，
后缀可能是 .xlsx 但实为逗号分隔文本），结构：

```
Name,TestIV 4.CH_REF(SCLC),...
Note,...
Time Stamp,...
Duration (s),13.96,...
[Parameter]
Start (V),-0.100000
End (V),1.300000
Step (V),0.010000
Area (cm^2),0.100000
...
[Result],Volt (V),I (mA),J (mA/cm^2)
[Raw Data],
,-0.100000,-0.000001033118036,-0.000010331180356
,...
```

要求：

- 每个样品一个文件，文件名即样品名（建议含批次信息）
- 电流单位 mA、面积单位 cm²（写在参数区，流水线自动读取）
- 同一批样品放同一个文件夹，把该文件夹路径填入 `sclc_pipeline.py`
  的 `CONFIG["input_dirs"]`
- jpg 曲线截图 / .mia 仪器工程文件 / Table.txt 等附属文件会被自动跳过
- 重复导出（同一数据多个副本）按内容 md5 自动去重

**隐私提醒**：原始实验数据请勿提交到公共仓库（.gitignore 已排除
`data/raw/` 与 `data/demo/`）。
