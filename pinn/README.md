# PINN 拟合 SCLC 迁移率（项目14）

用物理约束神经网络（PINN）从稀疏、含噪的暗态 J-V 数据中稳健估计 SCLC 迁移率，
解决传统"人工选窗口 + V² 回归"方法在小样本下的失效问题。

## 文件

| 文件 | 内容 |
|---|---|
| `pinn_sclc.py` | 第 1 部分：物理约束参数辨识（PyTorch + LBFGS）。合成数据蒙特卡洛验证 + 真实数据诊断 |
| `deepxde_inverse.py` | 第 2 部分：DeepXDE 逆问题——把泊松方程+漂移电流方程组直接写进损失函数辨识 μ |
| `synthetic_curve.png` | 合成 SCLC 曲线（欧姆区→V_TFL→SCLC 区） |
| `montecarlo_boxplot.png` | 300 轮小样本对比：物理约束拟合 vs 传统窗口/全点 V² 拟合 |
| `real_b3_4_fit.png` | 真实数据诊断图（放入自己的数据运行后生成，未随仓库分发） |

## 主要结论

1. **小样本稳健性**（8 个点 + 5% 噪声，300 轮蒙特卡洛）：
   - 无陷阱场景（m=2）：物理约束拟合中位误差 ~2%
   - 陷阱场景（m=3，Mark-Helfrich）：传统窗口 V² 法**系统性高估 ~52%**，
     全点 V² 法高估 ~20%，物理约束拟合仍保持 ~2%
   - 传统"高压窗口 V² 拟合"在 8 点采样下约 5% 的轮次凑不够 2 个点，直接失效
2. **真实数据诊断**：对真实器件样品拟合出指数 m=1.27（<<2），
   判定曲线处于欧姆区、未进入 SCLC 区，与独立实现的流水线判定一致——
   此时拒绝报告 μ，避免无物理意义的数字流入数据链。
3. **DeepXDE 逆问题（`deepxde_inverse.py`，框架验证 + 病态性发现）**：
   把 d/dx(φ''φ')=0（J 为常数的条件）作为 PDE 残差、实测 J-V 作为 ξ=1 边界
   条件、μ 作为 `dde.Variable` 随训练辨识。两个必踩的坑都有实测结论：
   - 逆问题必须补第三个边界条件 u'(0)=0，否则 u''u'=c 中 c 自由，欠定；
   - 即使补齐，**无陷阱 Mott-Gurney 问题的 PDE 逆问题仍是退化的**：
     解析解 u=ξ^1.5 唯一，μ 辨识等价于代数运算（即第 1 部分）；
     允许网络自由拟合形状时形状误差与 μ 互相补偿，偏差数倍且无法根除。
   结论：PDE-PINN 逆问题要发挥价值，需在方程中加入代数律没有的物理
   （陷阱动力学、扩散项），依赖复测的高电压 SCLC 数据——列为后续工作。

## 物理模型

- 欧姆区：J = qμn₀V/L（斜率 1）
- SCLC 区：J = (9/8)εε₀μV²/L³（Mott-Gurney，斜率 2）；
  指数陷阱时 J ∝ V^m（Mark-Helfrich，m>2）
- 陷阱填充极限电压：V_TFL = qn₀L²/2εε₀
- 器件参数：ITO/PCBM/SnO₂/PCBM/Ag 电子-only 结构，L≈20 nm，εr=3

## 环境

Python 3.14，PyTorch 2.x（CPU 即可），DeepXDE 1.15（`DDE_BACKEND=pytorch`）。
